# Sand Box - SVG vs PNG Performance Test

Проект для тестирования производительности отображения древовидных структур с использованием SVG и PNG изображений.

## Описание

Этот проект сравнивает производительность рендеринга древовидных структур с иконками в двух форматах:
- **SVG** - векторные изображения c вложенным base64
- **PNG** - растровые изображения (320x320px, масштабируются до 24x24px)

## Запуск проекта

```bash
# Установка зависимостей
npm install

# Запуск сервера
node server.js
```

Сервер будет доступен по адресу: http://localhost:3000

## API Endpoints

### SVG Tree Data
- `GET /api/tree-data` - получить все данные дерева SVG
- `GET /api/tree-children/:parentId` - получить дочерние элементы SVG

### PNG Tree Data  
- `GET /api/png-tree-data` - получить все данные дерева PNG
- `GET /api/png-tree-children/:parentId` - получить дочерние элементы PNG

## Структура проекта

```
├── components/tree/          # Компоненты дерева
│   ├── tree-data.js         # SVG дерево

```

## Особенности

- **Масштабирование изображений**: PNG изображения 320x320px масштабируются до 24x24px (20x20px на мобильных)
- **Base64 кодирование**: PNG изображения конвертируются в base64 для встраивания
- **Адаптивный дизайн**: Разные размеры иконок для десктопа и мобильных устройств
- **Производительность**: Сравнение времени рендеринга SVG vs PNG
